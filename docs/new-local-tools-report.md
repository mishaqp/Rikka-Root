# HTTP, часы, QR и документы

Семь новых инструментов объединены в четыре опции ассистента. Все четыре опции
по умолчанию выключены. Существующие инструменты и их правила одобрения сохранены.

1. **HTTP-запросы:** `http_request` поддерживает GET/POST/PUT/PATCH/DELETE/HEAD,
   строковое и JSON-тело, тайм-аут и ограниченное потоковое чтение. Ответ содержит
   статус, заголовки без Set-Cookie, текст или Base64 и признак усечения.
   GET/HEAD не требуют обычного подтверждения изменения; остальные методы требуют.
   Редиректы не выполняются автоматически. Изменяющие запросы не повторяются
   автоматически, включая ответ сервера 503. Отмена закрывает соединение.
   Секретные заголовки скрыты в сохранённой истории и карточках, включая HTTP
   внутри сценария. После восстановления истории скрытый заголовок нужно передать
   заново; маска не отправляется серверу.
2. **Будильники и таймеры:** `set_alarm`, `set_timer`, `show_alarms` используют
   системное приложение часов, подтверждение и открытый интерфейс Rikka-Root.
   Фоновые задачи эти инструменты не выполняют. Добавлено обычное разрешение
   `com.android.alarm.permission.SET_ALARM`, без нового специального доступа.
   Успешный результат означает передачу системного запроса; факт создания
   будильника или таймера следует проверить в часах.
3. **QR-коды:** `qr_generate` сохраняет PNG в приватном `/scratch` и передаёт
   изображение модели с поддержкой vision. `qr_scan` читает изображение из
   разрешённого пути, вложения или ранее созданного снимка экрана и возвращает
   найденные QR/штрихкоды. Используется ZXing core, без Google Play Services.
   Ограничены размер файла и число пикселей; добавлен только узкий доступ на
   чтение существующих снимков, без расширения прав обычных файловых инструментов.
4. **Чтение документов:** `read_document` извлекает текст PDF/DOCX/PPTX/EPUB
   существующим модулем document, соблюдает LocalFileAccess и отзыв доступа.
   `max_chars` по умолчанию 20000, максимум 65536. Для PDF доступны включительные
   `page_from`/`page_to` с единицы. Возвращаются `text`, `total_chars`, `truncated`,
   `pages` (число страниц PDF, для остальных форматов null). Временная копия
   удаляется при успехе, ошибке и отмене. Документ ограничен 32 МиБ; распакованное
   содержимое Office/EPUB — 64 МиБ.

## Проверка на телефоне

В настройках инструментов ассистента включите четыре новые опции. Для изображений
желательно выбрать модель с vision; текстовое распознавание QR работает и без него.

- HTTP: «Сделай GET https://httpbin.org/get и покажи статус». Затем:
  «Отправь POST https://httpbin.org/post с json {\"test\":\"привет\"}» — ожидается
  подтверждение. Для проверки истории можно использовать заведомо тестовый
  заголовок `X-Api-Key: test-only-123`; в аргументах карточки он должен быть скрыт.
- Будильник: «Поставь будильник на 08:30 с подписью Проверка». Одобрите запрос и
  проверьте приложение часов.
- Таймер: «Поставь таймер на 90 секунд с подписью Чай».
- Список будильников: вернитесь в Rikka-Root и попросите «Покажи будильники».
- QR: «Создай QR-код с текстом Привет, Rikka, размер 512, затем прочитай этот файл».
  Дополнительно приложите фотографию с несколькими кодами и попросите прочитать все.
  Для экрана: «Сделай снимок экрана и прочитай QR-код с него» (при включённом
  существующем инструменте снимков).
- Документы: поместите тестовые PDF/DOCX/PPTX/EPUB в разрешённую папку и попросите
  «Прочитай документ <путь>, максимум 500 символов». Для PDF: «Прочитай страницы
  2–3 из <путь>». Проверьте усечение и общее число страниц.

Локальная проверка: 214 тестов в 21 затронутом классе, без ошибок и пропусков.
До реализации получены падающие поведенческие тесты всех новых групп инструментов.
Независимый обзор после исправлений не выявил новых дефектов.
На JVM проверяются реальные Office/EPUB-файлы, ZXing и локальный HTTP-сервер.
Нативный MuPDF и фактическое создание будильника/таймера требуют проверки на Android.

## Адаптация из Agent

Новых семи инструментов в справочном Agent нет. Для нового API PDF использован
образец освобождения нативных ресурсов; прежний `parserPdf` оставлен без изменений.

| Файл Agent | Файл Rikka-Root | Адаптация |
|---|---|---|
| `document/.../PdfParser.kt` | `document/.../PdfParser.kt`, новый `parseRange` | Освобождение Document/Page/StructuredText; добавлены диапазоны, общее число страниц, проверка отмены и русская маркировка страниц. |
