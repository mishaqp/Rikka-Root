# Улучшения 1–3 и пакет G: план реализации

> Для исполнителей: применять существующий код Agent; координация параллельных подсистем и интеграция выполняются основной сессией.

**Цель:** устранить три подтверждённые проблемы и перенести browser, skill_import/js_skills, root screen_automation и workflows одним первоначальным push.

**Архитектура:** оригинальные классы Agent с необходимой адаптацией к upstream 2.5.6, ConversationConfig, AndroidKeyStore и существующим разрешениям/HARDLINE. Workflows имеют отдельную Room БД; фоновые действия используют существующий HeadlessTaskRunner. Screen automation использует RootShellManager, без Accessibility.

**Основание:** требования пользователя в текущей задаче и раздел «Rikka-Root: правила форка» в AGENTS.md. Отдельное согласование исходного дизайна не требуется: пользователь уже задал исходную реализацию, границы переноса, запрет новых спецдоступов и порядок выпуска.

**Ограничения:** Agent /workspace/refs/rikkahub-agent; ветка ccr-e93188a6-grrqko; исходные имена инструментов/параметры/@SerialName; русские UI строки; все новые группы выключены; никаких новых спецдоступов; APK/lint только Daily Build. Остальные предложения F не реализовывать.

**Проверки рисков:** повторная миграция/ошибка Keystore; одновременные и отменённые стримы; пути навыков/секреты между навыками; веб-контент возвращает подтверждения; headless не обходит текущие права и HARDLINE.
