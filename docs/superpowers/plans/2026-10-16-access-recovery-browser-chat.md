# Разрешения, восстановление и надёжность чата — план

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Пользователь уже поручил выполнить работу целиком, проверить, отправить и дождаться Daily Build; дополнительных остановок на согласование плана нет.

**Goal:** Разрешать доступ заранее, безопасно работать с общей памятью по явному выбору пользователя, восстанавливать прерванные операции и исправить подтверждённые сбои браузера и чата.

**Architecture:** Существующие системные запросы и SAF используются повторно. Доступ к памяти дополняется отдельной проверкой двух условий и границ тома. Долговременные записи выполняющихся операций восстанавливаются до запуска планировщиков без повторного выполнения действий. Внешний вид меняется только по пунктам запроса.

**Tech Stack:** Android/Kotlin, Compose, DataStore/kotlinx.serialization, Room, coroutines, Robolectric, Roborazzi.

**Spec:** Полное сообщение пользователя от 2026-10-16, задачи 1–5 и правила сборки; AGENTS.md.

## Global Constraints

- Ветка `ccr-e93188a6-grrqko`, начальный pull выполнен успешно; база `a0c79919`.
- Один новый manifest permission: явно разрешённый `MANAGE_EXTERNAL_STORAGE`.
- Настройка `Settings.fileToolsAllStorage`, `@SerialName("fileToolsAllStorage")`, по умолчанию false. Статус Android проверяется при использовании, а не только при открытии настроек.
- Выключенный переключатель оставляет SAF и прежние границы; persisted grants не изменяются автоматически.
- Запрещены `..`, выход через симлинки, `/data`, `/system`, общая `Android/data` и `Android/obb`. Одобрение инструментов сохраняется.
- Выдача через root только по нажатию пользователя; не запускать автоматический запрос su ради статуса экрана.
- Строки интерфейса на русском; названия инструментов/параметры сохраняются. Браузерные описания и политика Agent сохраняются.
- На изменение сначала тест и подтверждённое RED, затем исправление и GREEN. Gradle выполняется последовательно центральным агентом.
- APK только Daily Build. До каждой публикации точные полные команды test и lint с UTF-8. Исходный lint: 45 ошибок, новых не добавлять.
- Архивные скриншоты не изменяются. Только намеренные изменения живого `chat-after-stage5`; новый экран имеет отдельные снимки.
- Не более двух тематических публикаций, если итог превышает 60 файлов; каждая завершается зелёной сборкой. Если до 60 — одна публикация в конце.

## Review Focus

1. Отозванный Android-доступ или выключение настройки уже после создания файлового объекта должны остановить последующее обращение.
2. Алиасы памяти, съёмные тома и вложенные симлинки не должны открывать системные или частные папки.
3. Завершённые действия при аварии не повторяются; незавершённые получают понятный статус, частичный текст чата сохраняется.
4. Отмена JS-моста и редирект не должны повредить следующую команду или переключение мини/полноэкранного браузера.
5. Многострочный ввод, клавиатура, 320dp и шрифт 1.3 не должны закрывать последнее сообщение и кнопки.
