## Обязательные границы

- Ветка `ccr-e93188a6-grrqko`; перед каждым push — pull --rebase этой ветки, затем обычное зеркалирование в `claude/rikka-chat-redesign-stages-3-4-qrbava`.
- Три части выполняются строго последовательно; после каждой — зелёный Daily Build. APK собирает только Actions.
- Каждый новый баг фиксируется регрессионным тестом: сначала воспроизведение на прежнем коде, затем проверка исправления. Существующие тесты сохраняются; Lint во всех модулях — 0 ошибок без подавлений.
- Сохраняются файловые границы, секреты и существующие политики подтверждения. Браузеру не добавляются фильтры и подтверждения сверх upstream Agent; пункт 13 в части browser_open исключён пользователем.
- Пользовательские и модельные сообщения — по-русски; ключи JSON и параметры остаются английскими. Без новых зависимостей, если задачу решают существующие.
- Не меняются данные пользователя и схема Room без отдельной прямой миграции с тестом. Параллельные изменения другого разработчика сохраняются.

## Проверки особых случаев

- Реальная отмена родительской корутины остаётся отменой; локальный timeout инструмента возвращается модели как ошибка.
- Большой результат остаётся доступным пользователю, но не переполняет запрос провайдера; UI получает корректный JSON.
- Управление ассистентами и MCP не теряет связанные данные, не раскрывает секреты, сверяет одобренный снимок перед изменением.
- Работа через SAF сохраняет фактические имена и безопасность путей; большие каталоги не требуют полного листинга ради одного имени.
- Неоднозначные аргументы не превращаются в опасное действие и не обходят подтверждение.
