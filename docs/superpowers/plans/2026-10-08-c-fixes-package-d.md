## C: диагностика и реализация (25 файлов)

- Камера: отдельный CameraX host с видимым просмотром, однократным автозахватом, ограниченными таймаутами этапов и ACTION_IMAGE_CAPTURE/FileProvider fallback. Состояние запроса переживает пересоздание Activity и внешний переход; отмена генерации освобождает ресурсы. Не менять отмену микрофона/защищённых форм.
- SMS: отдельные sent/delivery callbacks, ограниченное ожидание около 30 секунд, различать отправку, ошибку Android/модема и таймаут; частичную отправку не повторять автоматически.
- Speech: системный recognizer, затем настроенный ASR из chat speech; общий factory без нового хранения секретов, диагностировать выбранные движки без ключей/адресов. Сохранять отмену и освобождение микрофона.
- Проверить чистую логику переходов/таймаутов/результатов и скомпилировать app. Отдельный коммит без push.

Локально подтверждены RED регрессии камеры, SMS и ASR; итоговая компиляция app/speech и 56 выбранных тестов прошли. Независимое ревью исправлений выполнено. Новых разрешений C нет; добавлены зависимости CameraX.

## D: проект и реализация (до 40 файлов)

Восемь выключенных по умолчанию опций Agent: files, external_storage, archive, media_player, media_scanner, download, system_intents, app_launcher. Зарегистрировать все 40 имён инструментов в политике одобрения, сохранить имена сериализации и происхождение AGPL.

- Общая LocalFileAccess: выбранный workspace через существующий ConversationConfig resolver, выделенная scratch/upload область и явно выданные SAF grants; запрещать внутренние настройки/БД, обход пути и symlink escapes, проверять рекурсивные дочерние пути.
- Файлы: чтение/запись/список/копирование/перемещение/удаление/поиск, batch, изображение и открытие. Источник закрывается и при раннем выходе назначения (0ff79698).
- SAF: только пользовательский tree picker и persisted URI grants; без MANAGE_EXTERNAL_STORAGE. ZIP: защита zip-slip, лимиты распаковки, отмена/очистка частичных результатов.
- Медиа: native playback service/audio focus, scanner, download и write_text_file с безопасными путями и ограничениями.
- Native intents и launcher: фиксированные действия, проверенные аргументы, видимые приложения, без Accessibility/QUERY_ALL_PACKAGES/root shell.
- Уже имеющийся cancellation-safe SAF export (29d1343f) сохранить и проверить.
- Интеграция: LocalToolOption/LocalTools/ChatToolFactory/ToolPermissionPolicy, manifest/dependencies, русские настройки. Нормальное FGS media playback разрешение; существующий WRITE_EXTERNAL_STORAGE только на API 26–28, если нужен конкретному download.
- До редактирования публиковать общий interface; независимые исполнители владеют непересекающимися файлами. Только координатор запускает Gradle и делает коммиты.

Итог D: 37 файлов, восемь выключенных по умолчанию опций, 40 инструментов в реестре одобрения. Компиляция app и 71 выбранный тест прошли без ошибок/пропусков. Независимое ревью проверило закрытие потоков, исключительное создание назначения, алиасы SAF, восстановление исходного файла при отмене (включая close), ZIP и экспорт. Медиасканер поддерживает явно выданные SAF-файлы локальных накопителей; облачные документы возвращают понятную ошибку.

Разрешения D: добавлено обычное FOREGROUND_SERVICE_MEDIA_PLAYBACK. Существующее WRITE_EXTERNAL_STORAGE (maxSdkVersion=28) запрашивается только при включении Download на Android 8–9, с объяснением и обработкой отказа; выдача через root — только кнопкой пользователя. SAF выдаёт пользователь через системный выбор папки. Спецдоступы не добавлены. Нового хранения секретов нет; постоянные SAF grants хранятся Android, не экспортируются в бэкап.
