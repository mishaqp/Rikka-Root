# Новые локальные инструменты

Основание: явный запрос пользователя от 17 октября 2026. Ветка
`ccr-e93188a6-grrqko`; начальный `git pull --rebase` выполнен до изменений.

## Границы

Добавить семь инструментов и четыре отдельные, выключенные по умолчанию опции.
Существующие инструменты, сохранённые опции и правила их одобрения сохранить.
Все новые описания, результаты и ошибки — на русском. У новых опций должны быть
стабильные `@SerialName`, регистрация в каталоге, разрешениях, метаданных,
фоновом исполнении и представлении сообщений.

## Решения

1. `http_request`: только HTTP(S), без userinfo, методы GET/POST/PUT/PATCH/DELETE/HEAD.
   GET/HEAD читают без запроса на изменение; остальные используют обычное одобрение
   инструмента. Строгие параметры, ограниченное чтение потока, отмена закрывает вызов.
   Автоматические редиректы и повторы изменяющих запросов отключены. Ответ 3xx
   возвращается модели. GET/HEAD могут повториться по правилам сервера (503).
   Клиент сохраняет настройки сети приложения, исключая перехватчики,
   записывающие содержимое запросов. Ответ отмечается как веб-контент.
   Секретные заголовки скрываются при сохранении и отображении истории; исходные
   аргументы остаются доступны текущему одобренному вызову. После перезапуска
   замаскированные значения нельзя отправить: пользователь должен передать их заново.
2. `set_alarm`, `set_timer`, `show_alarms`: системные AlarmClock-интенты,
   `skip_ui=true`, обычное разрешение SET_ALARM. Только активное приложение;
   в headless-вызовах запрещены. Дни недели Android Calendar: 1–7,
   воскресенье–суббота. Успех означает передачу запроса приложению часов.
3. `qr_generate`, `qr_scan`: существующая зависимость ZXing core. PNG сохраняется
   в приватном `/scratch`; изображение включается в результат для модели с vision.
   Чтение локальных путей проходит LocalFileAccess; вложения и сгенерированные
   снимки получают узкое право чтения, не распространяющееся на произвольный кэш.
   Распознаются все найденные QR/штрихкоды. Размер входного изображения ограничен.
4. `read_document`: существующий модуль document, PDF/DOCX/PPTX/EPUB.
   Источник открывается через LocalFileAccess, временная копия удаляется во всех
   исходах. PDF получает новый API диапазонов, старый API сохраняет поведение.
   Страницы начинаются с единицы, границы включаются. `pages` — общее число страниц
   PDF, для остальных форматов null. `total_chars` считается до обрезки результата.
