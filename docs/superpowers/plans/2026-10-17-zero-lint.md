# Нулевой порог Android Lint

Запрос пользователя: устранить все 45 унаследованных ошибок без подавлений,
сохранить поведение и ресурсные тексты, установить нулевой порог CI.
Начальный pull --rebase выполнен; исходный коммит db2c32f2ad12fe79bea822661a281cd61f3b7adc.

## Границы и решения

- Не изменять data/ai/tools/** и параллельные изменения другого разработчика.
- 41 чтение ресурсов из LocalContext заменить реактивным чтением ресурсов Compose.
  Прямые UI-строки использовать через stringResource/pluralStringResource.
  В отложенных обработчиках использовать rememberUpdatedState со строкой или
  LocalResources.current; сохранять IDs, format args и момент форматирования.
- В трёх composable читать locale из LocalConfiguration.current.locales[0].
  Проверить ключи remember и захват значений, зависящих от locale.
- ChatList получает nullable Activity через LocalActivity.current без Context cast.
- MAX_LINT_ERRORS=0; любой ненулевой exit lint отвергать. Не скрывать проблемы
  анализа даже при XML с нулевым числом ошибок. Старые lint-тесты ужесточить,
  добавить проверки границы 0/1 и завершения процесса.
- AGENTS.md обновить на правило отсутствия ошибок без подавлений.

## Исполнение

1. Подтвердить исходные 45 ошибок отчётом и локальным lint.
2. Исправить непересекающиеся группы файлов: backup (20), media/UI (13),
   assistant/settings (8), locale/Activity (4). Gradle и git выполняет только root.
3. Проверить Python-тесты CI, затронутые Android unit-тесты и ./gradlew lint
   во всех модулях, без baseline, suppressions и отключения проверок.
4. Независимый обзор отложенных значений, locale и соответствия границам.
5. Коммит, git pull --rebase origin ccr-e93188a6-grrqko, нормальный push.
   Отзеркалить коммит в claude/rikka-chat-redesign-stages-3-4-qrbava.
6. Дождаться зелёного Daily Build и подписанного APK, проверить полный lint=0,
   опубликовать список изменённых файлов и ссылки.
