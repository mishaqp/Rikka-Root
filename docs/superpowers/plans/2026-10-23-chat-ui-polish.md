# Точечные исправления интерфейса чата

**Запрос:** «Проверяй дальше, интерфейс чата ищи баги и неровности но не ломай». Текущая база `5148012dbbff6fc1ea28b57d046a43fecff26c31`, ветка `ccr-e93188a6-grrqko`.

**Цель:** исправить воспроизводимые дефекты существующих действий и их состояний с сохранением оформления, размеров, истории, API генерации, Root и разрешений.

## Подход

1. Вложения: существующий helper `Context.openLocalFile` безусловно преобразует URL в File, не задаёт MIME и не обрабатывает ошибки. Добавить проверку file/content/http/https, корректный read-only VIEW intent с MIME и понятный отказ вместо исключения. Использовать существующий FileProvider и grants; не копировать файлы и не расширять доступ. Текущий URL API и callbacks сохранить; MIME документа передавать явно.
2. Перевод: русский picker имеет российский флаг у китайского Locale и не предлагает русский язык. Исправить соответствие видимого имени/флага реальному Locale, добавить существующему универсальному переводу выбор русского. Сохранить остальные языки и очистку перевода.
3. Ветки: стрелки на первой/последней альтернативе остаются enabled с no-op. Передавать фактическое disabled-состояние и русские accessibility labels, сохранив габариты, alpha, индексы и id-based callback.
4. Озвучка: все кнопки сообщений читают глобальное isSpeaking, поэтому каждая выглядит активной и чужой toggle останавливает речь. Связать выделение и stop с владельцем сообщения; запуск другой реплики переключает чтение. Сохранить обычные speak/stop/flush, autoplay, pause/resume и voice backend. Изолированная работа поручена `chat_tts_controls`; сначала только регрессии, implementation после общего RED.
