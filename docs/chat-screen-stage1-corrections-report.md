# Правки этапа 1 после проверки телефона

Первый коммит текущей задачи содержит только пять запрошенных правок, их проверки и снимки. Перенос сообщений этапа2 выполняется следующим коммитом.

- Модель возвращена первой кнопкой в поле ввода: существующий SVG значок модели/провайдера20dp в слоте32dp, fallbackHugeIcons; tap открывает существующий ModelListSheet, long press показывает полное имя. Выбор вызывает прежний callback ConversationConfig.
- Шапка содержит только16dp аватар·название, центрированные в промежутке между drawer и правыми кнопками. Текст onSurface/однастрока/ellipsis; rename/menu/preview/newchat/workspace сохранены.
- Контекст: существующий ModelRegistry.MODEL_CONTEXT_LENGTH даёт ёмкость известных моделей; кольцо показывает clamp(actualPrompt/window). Если ёмкости нет, показывается labelSmall/onSurfaceVariant214K; tooltip сохраняет реальные токены. Неизвестный usage скрыт,0 сохраняется. Новых полей модели не добавлено.
- Placeholder «Сообщение» в основном поле и полноэкранном редакторе.
- Навигация36dp, surface alpha0.85light/0.4dark, outline1dp. Видима во время движения и1500ms после его остановки; tap продлевает timeout. Существующие настройки стороны и showMessageJumper сохраняются. Дополнительный gutter36dp на выбранной стороне не даёт кнопкам налезать на содержание; индексы переходов, volume keys, auto scroll и capture guard сохранены.
